# OFS Strict v13 Custom Build / OFS 严格 v13 定制版

## English

This branch contains the custom strict v13 OFS source based on [OpenFunscripter/OFS](https://github.com/OpenFunscripter/OFS).

### Main features

- Frame-accurate forward and backward keyboard stepping.
- Right-drag rectangle selection constrained by time and height.
- `Ctrl` + right-drag adds to the rectangle selection.
- Rectangle paste is isolated from the original left-click selection/paste workflow.
- `Ctrl+B` inserts copied action segments at selected anchors without replacing existing actions.
- Lnip/Rnip graph support.

### Download

Windows x64 users can download the ready-to-run package from the [Releases](https://github.com/Aly0-funscriper/OFS/releases) page. Extract the ZIP and start `OpenFunscripter.exe`.

## 中文

此分支是基于 [OpenFunscripter/OFS](https://github.com/OpenFunscripter/OFS) 的严格 v13 定制源码。

### 主要功能

- 键盘前进、后退按视频帧精确跳转。
- 鼠标右键拖动进行矩形选择，同时限制时间范围和高度范围。
- 按住 `Ctrl` 再用右键拖动，可追加矩形选择。
- 矩形选择的粘贴逻辑与原有左键选择、左键粘贴相互隔离。
- 按 `Ctrl+B` 将复制的完整 action 段插入到选中点位，不覆盖已有点位。
- 支持 Lnip/Rnip 图表。

### 下载

Windows x64 用户可在 [Releases 发布页](https://github.com/Aly0-funscriper/OFS/releases) 下载可直接运行的压缩包。解压后运行 `OpenFunscripter.exe` 即可。

本项目保留原项目许可证和依赖说明；源码分支适合开发者使用，普通用户建议下载 Release 压缩包。
